# Proyecto-Javascript

## Proyecto 1: Tablero de Ajedrez Automático

### Objetivo
Crear un tablero de ajedrez de 8x8 usando JavaScript y bucles anidados. El tablero alterna colores (blanco y negro) automáticamente.

---

## Proyecto 2: Mini-juego de Animación

### Objetivo

Juego sencillo de "scroll lateral" donde un personaje debe saltar obstáculos para evitar perder. El juego consta de una escena donde un personaje (emoji de un alien) esté en el suelo. El obstáculo (emoji de un planeta) se mueve constantemente de derecha a izquierda. El usuario debe presionar la tecla Espacio para saltar y esquivarlo.
